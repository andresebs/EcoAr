# ECO-AR · Naturaleza en tus manos

**[Abrir ECO-AR en tu celular](https://andresebs.github.io/EcoAr/)**

Web móvil de realidad aumentada para la Universidad de San Buenaventura. No necesita instalación ni cuenta de GitHub para usarla.

## Cómo usarla

1. Abre el enlace anterior en Chrome de Android.
2. Toca **Ver logo** para identificar la imagen de referencia. Debe estar completa, incluido el nombre de la universidad, en otra pantalla o impresa.
3. Toca **Escanear logo** y permite usar la cámara.
4. Apunta al logo con buena luz. Aparecerá el modelo seleccionado.
5. Elige pato, ganso, pavo real o lechuga; cambia la etapa de crecimiento de la lechuga desde el selector.

Arrastra para girar y pellizca para ampliar. También puedes usar los botones de giro, zoom, rotación automática y restablecimiento. **Volver al visor 3D** apaga la cámara. El visor funciona sin cámara.

## Versión 2.1.0

Diseño para celular vertical y horizontal, pantalla completa, ayuda e información de especies, mensajes accesibles y manejo de permisos y errores. La cámara se procesa en el dispositivo; no se suben imágenes a un servidor propio.

El código fuente completo, los ocho GLB, las imágenes originales, el marcador, los scripts y la documentación están en `ECO-AR-movil-proyecto-2.1.zip`. La raíz de este repositorio contiene la versión compilada, lista para GitHub Pages.

Las pruebas automatizadas verifican cinco tamaños de pantalla, controles, gestos, selección, reconocimiento y pérdida del logo mediante vídeo sintético, cancelación de cámara y recuperación de errores. Queda pendiente la verificación con cámara real en teléfonos físicos y el logo impreso. Los modelos son representaciones educativas estilizadas.
